# Virtual ELISA Lab

A 96-well ELISA workflow simulator.

**Live demo:** https://macaly-j4uz4ttgyvgnfvu40ibsinyw-prod.macaly-app.com

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- Full workflow from sample addition to plate read, with animated pipetting
- 4-parameter logistic standard curve and back-calculation of unknowns
- Fault-diagnosis mode (hook effect, edge effect, incomplete wash and more) with a leaderboard
- Lab notebook log and downloadable assay report

## Tech stack
Built on Macaly Cloud (leaderboard backed by Convex).
